## 脱敏方式

采用字段允许列表重新构成公开记录，避免直接复制包含多层转义文本的完整错误。删除本机绝对路径、电脑用户名、IP/主机地址、进程号、访问凭据、账号与团队信息、工程/会话/窗口/文档标识。案例仅用 A/B 标记，器件位号和引脚号作为合成工程技术数据保留。记录保留日期和时长，不保留不必要的精确活动时间。

署名使用仓库所有者指定的公开标识，不包含其真实姓名、邮箱或电脑账户。公开文本和 JSON 在提交前检查路径、网络地址、凭据样式、账号信息及文件清单。

## 可信度与复现边界

这些是依据本地记录整理的发布摘录，不是完整原始日志，不是独立第三方审计，也不是读者可直接执行的复现包。错误消息片段保留原文，其余说明标为摘要。源码和完整环境未公开，因此读者不能仅靠本仓库重跑 332 项测试。

工程数据摘要不是新编造的演示电路，也不包含可导入的封装、符号库或完整工程。原始归档仍是维护者核对依据；公开摘录不修改、替代或把原失败回执升级为成功。若后续分享更多工程，应单独检查工程内部元数据及第三方再分发权。
