# 能力契约

状态截至 2026-10-18。以下“支持范围”均指个人项目在已记录案例和前置条件下的观察，不等于对任意工程或任意版本的承诺。“局部通过”指有明确案例和前置条件，不等于面向任意工程开放。当前路线停止后，不继续派发编辑器操作。

| 能力 | 支持范围/已做工作 | 必须拒绝或保留缺测的情况 | 如何判定成功 | 部分失败后的处理 |
|---|---|---|---|---|
| 工程绑定与快照 | 显式绑定目标，读取器件、引脚、网络及可用几何；双读和内容签名 | 文档缺失、父工程冲突、重复身份、窗口不匹配、范围不完整 | 文件清单与会话文档一致，采集覆盖明确，前后目标一致 | 保存观测和具体原因；仅明确未就绪可有界等待 |
| 只读连通与审查 | 网络分区、悬空、同器件异常同网、设计意图差分等 | 将未采集数据当作无问题；把连通/DRC 当成功能正确 | 报告有对象定位、依据和缺测；检查前后设计一致 | 标记 unavailable/unverified，不自动修复 |
| 布局规划 | 按模块、固定器件、几何和连接约束提出候选，部分案例执行资格通过 | 通过硬编码案例坐标规避约束；未验证的旋转、带铜移动 | 目标姿态、模块关系、间距及非目标对象保持条件均满足 | 记录已完成位置，停止后续步骤；重算不能覆盖旧回执 |
| 原理图连线 | 显式引脚连接、分支及 NC 的有限实机验证 | 只看线条碰上去就当导通；未知引脚或隐式跨网合并 | 回读真实引脚分区和几何，比较期望网络及非目标网络 | 部分写入保留现场，不能盲重放或换后端续写 |
| 标签 | 同名标签/命名网的专项创建与核验 | 将标签文字相同当作已证明连接；未验证的表示转换 | 标签、锚点/短线、网络分区、非目标对象及持久化符合计划 | 保存原失败；用新观察报告当前状态，不改写历史 |
| 原理图移动 | 无连线对象的受控平移及几何专项；部分命名组语义已实测 | 默认带线拖动、匿名网保连移动、静默把实体线改成端口 | 位置改变且网络、线形及非目标对象符合事先约定 | 立即停止，区分已移动与未完成核验；不假定自动恢复 |
| PCB 移动 | 无铜条件下的特定平移计划与逐件保存重载 | 已连铜但要求铜跟随、未经资格验证的自动布局应用 | 器件与焊盘几何、网络、源内容及保存重载一致 | 已保存步骤可能保留；未确认时不执行余下步骤 |
| 保存与重开 | 文档保存、回读及部分小案例独立重开审计 | 缺少文档保存证据、身份冲突、仍有未知调用时关闭/重开 | 保存回复之外，还需重读内容；重开后重新绑定并核验全部范围 | “保存通过”和“重开未知”分别报告，不宣称整体完成 |
| 超时隔离 | 两通道共享状态，新生产进程不能绕过未确认操作 | 把客户端超时当取消，删除状态或换目录继续派发 | 故障后后续渲染端调用被阻止，旧记录保持 | 保持隔离；目前没有通用安全自动恢复承诺 |

## 证据强度

接口返回成功只是第一层。对象几何正确、网络正确、非目标对象未改变、保存后可回读、重开后仍一致是不同检查，必须分别签核。截图可以辅助检查可读性，不能替代网表和持久化证据。

离线规划通过、模拟执行通过、单次实机通过、连续完整流程通过和硬件有效是不同等级。详细案例映射见[开发进展](progress.md)。
